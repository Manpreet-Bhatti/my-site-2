# Getting started

## Let's Install

Install modules

```shell
cd my-site-2
pnpm install
```

## Let's Build

Start a development server

```shell
pnpm dev
```

or
Create and start a production build

```shell
pnpm build
pnpm start
```

## Let's Customize

> Fork this project for your customization ideas!
>
> Tip: You should see if these changes work in the development server before building and starting.

### Colours

To change colours, edit the CSS variables in `./app/globals.css`.

### Projects & Work

To showcase your projects and work experience, edit the content files:

- `./content/projects.ts` — add or update your projects
- `./content/work.ts` — add or update your work history

### Socials

Let others know where they can find you by editing the links in `./app/page.tsx`.

### 3D Model

The sakura tree 3D model lives at `./public/sakura_tree.glb`. Swap it out with your own `.glb` file and update `./components/sakura-viewer.tsx` accordingly.

## Let's Publish

There are many great hosting platforms that will have services to showcase your static websites. I used Next.js for this website which goes perfectly with [Vercel](https://vercel.com/); I advise you use it!
